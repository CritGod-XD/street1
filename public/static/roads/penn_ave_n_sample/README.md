# Penn Ave N dataset

This is the canonical inspection dataset folder for Penn Ave N.

- `index.json` is the only frame manifest used by the app.
- Each frame image and its matching annotation JSON are stored together here.
- There are currently 120 image frames and 120 matching annotations.
- Image and annotation paths in the index are relative to this folder.

For the upload convention for future roads, see `../README.md` and `../_template/README.md`.
